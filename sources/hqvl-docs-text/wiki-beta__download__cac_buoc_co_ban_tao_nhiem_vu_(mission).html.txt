🏆 Nội dung
Nay rảnh mình viết cơ bản về Mission và các bước cơ bản để tạo ra 1 tính năng mới ae nào biết rồi thì bỏ qua nha 
    OpenMission(id)

id khai báo trong tập tin sau:
/home/jxser/server1/settings/task/missions.txt

theo id sẽ call vào InitMission() trong thư mục đã được khai báo
Mission được set theo index riêng của map đó Ví dụ để mở mission cho map 999, viết script như sau
warmap = SubWorldID2Idx(idMap) -- lấy index của map trong gs
SubWorld = warmap              -- trỏ index map để thao tác
OpenMission(84)

đối với hàm CloseMission cũng truyền tham số tương tự. Hàm này sẽ được call trong EndMission()
-- giống với SetTask cho player mà dùng SetTask cho index map 
-- VD: có thể gặp trong mision vượt ải (dmg to quá vẫn có tỉ
--  lệ mis ngáo khi set để đếm số quái hạ gục)
SetMissionV(task-id , 0) 

-- ID mission -- id tasktime (*) -- timer 18*60 = 1phut
StartMissionTimer(84, 155, 18*60)

task-id time khai báo trong
/home/jxser/server1/settings/timertask.txt

cứ sau timer quy định sẽ theo id timer gọi vào file chỉ định func OnTimer() dùng để đếm timer tính năng hoặc timer kết thúc
Để dừng timer, sử dụng hàm StopMissionTimer
StopMissionTimer(idmsissnion,idtimer)

Để add player vào team hoặc phe phái trong mision hiểu vậy cũng đc
AddMSPlayer(84, 1) -- id id misison, number team

ví dụ trong battle tống kim
AddMSPlayer(84, 1); -- tống
AddMSPlayer(84, 2); -- kim 

Sau khi player đc add vào thì khi out game hoặc thoát khỏi map sẽ load func OnLeave(RoleIndex) trong đường dẫn id misison khai báo và có thể truy xuất indexplayer để thao tác lên all nv đang tham gia mission đó.
VD: thưởng toàn bộ player tham gia sẽ được đưa ra ngoài map khi hết giờ
GetNextPlayer(84,idx, idteam muốn get)
SetDeathScript("\\script\\game\\playerdeath.lua")

Hàm dùng để set khi nv bị hạ gục sẽ load func OnDeath(nNpcIndex) trong file lua đã set trên.
Việc còn lại là sắp xếp logic và bạn sẽ có 1 kịch bản hay để thưởng thức.
Chúc ae thành công!
