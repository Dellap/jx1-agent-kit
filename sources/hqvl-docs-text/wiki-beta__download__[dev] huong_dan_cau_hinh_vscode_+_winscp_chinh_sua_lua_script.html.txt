🏆 Nội dung
Nếu bạn chưa có VS Code hoặc WinSCP, có thể tải về trong mục ⬇️ Tài nguyên bên dưới bài viết.1. Cấu hình VS Code
Mở Visual Code
Từ màn hình chính, bấm Settings ở góc trái dưới. Chọn Create a new profile. Nhập tên cho Profile mới là JX-VoLamQuan.

Mở settings.json để thiết lập cấu hình cho Profile mới này.
Từ menu File, chọn Preferences. Sau đó chọn Settings. (Có thể mở nhanh bằng phím tắt Control + , hoặc ⌘ + ,)
Ở màn hình Settings, bấm vào biểu tượng 📄 ở góc phải trên (biểu tượng giống hình trang giấy A4).

Cửa sổ soạn thảo cho settings.json mở ra, thay thế bằng nội dung bên dưới đây
{
    //Set font cho edit với font family tờn sonkt_Source Code Pro
    "editor. fontFamily": "sonkt_Source Code Pro",

    //Thiết Lập pattern va rule cho Symbol Masks
    "symbolMasks .masks": [
        {
            //SymbolMasks sẽ hoạt động với những file ngụn ngữ được Liệt kd dưới đõy.
            "languages": [
                "lua",
                "plaintext",
                "ini",
                "log",
                "c",
                "csharp",
                "cpp",
            ],
            "pattern": [
                {
                    //Trong "" đó cú chữ "ư" mó Unicode, trdnh duyệt khụng hiển thị
                    "pattern": "",
                    //Thay thế ký tự được Liệt kd trong pattern bằng kd tự này
                    "replace": "ư",
                }
            ]
        }
    ],
    //Bỗ qua thụng bdo trust files khi md folder mới
    "security.workspace.trust.untrustedfiles": "open",
    "security.workspace.trust.enabled": false,
    //86 qua highlight những ky ty unicode (tiếng việt cú dấu là những ký ty unicode)
    "editor.unicodeHighLight.ambiguousCharacters": false,
    "editor.unicodeHighlight.invisibleCharacters": false,
    //VÕ ae dev jx, nờn sử dụng mé 15088591 làm mặc định. Bạn cú thé thiết lập mặc định này cho Workspace dựng riờng dé dev jx
    "files.encoding": "iso88591",
    "editor.guides.bracketPairs": "active",
}

Bấm Ctrl + S để lưu là xong.2. Cấu hình WinSCP
Mở WinSCP

Bấm phải chuột lên tập tin Lua bất kỳ, chọn Cấu hình... như Hình 01. 

Trong Mục Biên tập ở màn hình tiếp theo, bấm nút Thêm trình biên tập mới (Hình 02). 

Ở màn hình tiếp theo, chọn “Trình biên chọn bên ngoài”. Bấm Tìm duyệt và truy cập đến thư mục cài đặt của VSCode (mặc định là trong thư mục Program Files).

Thêm vào cuối đường dẫn tham số --profile JX-VoLamQuan !.! như Hình 03. 

Bấm Đồng ý để hoàn tất.
Vậy là bạn là hoàn tất cấu hình cho cả VS Code và WinSCP. Từ bây giờ, mỗi khi bạn bấm vào tập tin Lua bất kỳ trên WinSCP. VS Code sẽ được sử dụng làm trình soạn để mở tập tin Lua với profile bạn đã thiết lập ở trên.
