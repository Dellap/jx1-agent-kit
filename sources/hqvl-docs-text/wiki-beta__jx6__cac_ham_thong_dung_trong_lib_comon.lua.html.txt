🏆 Nội dung
We hereby bring up most of popular utility functions in the library common.lua. Hope that help you improve the time speding for coding Lua.
script/lib/comon.lua

quickly retreiving a table (an array) from a string
unpack('1,2,3,4,5,6') -- -> {1,2,3,4,5,6}

an inline if then else (ternary conditional operator)
iff

converting a variable to number with zero fallback value.
tonum -> safely_tonum

Padding dash characters to align the given string
strfill_left
strfill_right
strfill_center

Using for.. in .. do instead of for..do..end
for key,value in {["Kháng"] = 1} do:
    print(key)
end
